Core Gameplay
Endless runner mechanic: player drives a car continuously forward on a multi-lane road.


Multiple lanes: road divided into 3 (or more) lanes for lane-switching.


Player controls:


Lane switching (left/right arrow keys).


Acceleration/brake (optional)
Bunny hop
Limited in number. Regenerates over time. 
Obstacles:


Moving cars (traffic).
Difficulty increase: wrong way drivers


Static broken-down cars.


Police roadblocks (barriers).


Collision detection: collision with an obstacle reduces car health. 
Power-ups such as tank mode, slow motion, nitro


Environment & Visuals
3D environment rendered using OpenGL.


Road and lanes with OpenGL functions


Sky rendering (gradient).


Background scenery: trees, roadside objects, repeating background elements.


Basic lighting to simulate depth and realism.


Third-person camera view positioned behind the player’s car.
Day/night cycle, changes vehicle visuals(headlights)
Sense of speed (zoom camera in /out based on speed)


Scoring & Progression
Scoring system based on distance traveled.


Increasing difficulty over time:


Faster obstacle spawn rates.
Increase number of tracks


High score tracking and display.



User Interface
Heads-up display (HUD) with:


Current distance (score).


High score.


Game over screen showing score and restart/exit options.


Technical Features
OpenGL rendering of cars, road, and scenery.


GLUT input handling for keyboard controls.


Randomized obstacle spawning for replayability.


Consistent gameplay speed maintained using GLUT timers.


Lane-based movement system (discrete lane switching rather than free steering).


Optional Features
Multiple environments (city, forest, desert).
